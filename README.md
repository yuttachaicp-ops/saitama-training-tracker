# Saitama Training Tracker

แอปติดตามการออกกำลังกาย **12 สัปดาห์** สำหรับผู้เริ่มต้น ใช้น้ำหนักตัวล้วน (bodyweight) ร่วมกับการวิ่ง
ทำงานเป็นเว็บแอป เปิดได้ทั้งคอมพิวเตอร์และมือถือ ข้อมูลเก็บอยู่ในเครื่องของคุณเท่านั้น

> แอปนี้เป็นเครื่องมือช่วย **ติดตามผล** การออกกำลังกาย ไม่ใช่เครื่องมือวินิจฉัยหรือคำแนะนำทางการแพทย์

## สิ่งที่แอปทำได้

| ส่วน | รายละเอียด |
|---|---|
| **หน้าหลัก** | สัปดาห์ปัจจุบัน, ความคืบหน้าของโปรแกรม, การฝึกวันนี้, สตรีค, เวลาฝึกสะสม, ระยะทางวิ่งสะสม, สถานะรายวันของสัปดาห์นี้ |
| **ฝึกประจำวัน** | เช็กลิสต์ท่าออกกำลังกาย, จับเวลา (เริ่ม/พัก/ทำต่อ), บันทึกจำนวนครั้งจริงรายเซต, จับเวลาพักระหว่างเซต, ความรู้สึกหลังฝึก, หมายเหตุ, สรุปผลเมื่อจบ |
| **บันทึกการวิ่ง** | Running A / Running B / Long Run, จับเวลา, กรอกระยะทางเอง, คำนวณ pace, สถิติการวิ่งรวม |
| **โปรแกรม 12 สัปดาห์** | ดูได้ทุกสัปดาห์ ทุกวัน, สถานะ สำเร็จ/วันนี้/ยังไม่ได้ฝึก/รออยู่/วันพัก, ปรับจำนวนครั้งและเซตรายสัปดาห์ได้ |
| **สถิติ** | กราฟความสำเร็จรายสัปดาห์, พัฒนาการวิดพื้น/สควอต/แพลงก์/ก้าวขาถอยหลัง, ระยะทางวิ่งรายสัปดาห์และสะสม, สถิติส่วนตัวที่ดีที่สุด, กรองตามช่วงเวลา |
| **ประวัติการฝึก** | ค้นหา, กรองตามประเภทและช่วงวันที่, เปิดดูรายละเอียด, แก้ไข, ลบ (มีการยืนยันก่อนลบ) |
| **ความสำเร็จ** | 13 รายการ ปลดล็อกอัตโนมัติจากข้อมูลจริงเท่านั้น |
| **ตั้งค่า** | โปรไฟล์, วันเริ่มโปรแกรม, ระดับความยาก, เวลาพัก, ธีมมืด/สว่าง/ตามระบบ, แจ้งเตือน, ส่งออก/นำเข้า/สำรอง/รีเซ็ตข้อมูล |

กราฟและตัวเลขทุกจุด **คำนวณจากเซสชันที่คุณบันทึกจริง** ไม่มีข้อมูลตัวอย่างปลอมปนอยู่
ถ้ายังไม่มีข้อมูล แอปจะแสดง Empty State พร้อมคำแนะนำให้เริ่มบันทึก

## โปรแกรมฝึก 12 สัปดาห์

ฝึก 6 วัน พัก 1 วัน (อาทิตย์)

| วัน | ประเภท | ท่า |
|---|---|---|
| จันทร์ | Strength A | วิดพื้น, สควอต, Glute Bridge, Dead Bug, เขย่งน่อง |
| อังคาร | Running A | วิ่ง 1 นาที / เดิน 2 นาที × หลายรอบ |
| พุธ | Strength B | วิดพื้นเอียง/คุกเข่า, ก้าวขาถอยหลัง, Hip Hinge, Bird Dog, แพลงก์ |
| พฤหัส | Running B | วิ่งเบาหรือเดินเร็วต่อเนื่อง |
| ศุกร์ | Strength C | วิดพื้น, สควอต, ก้าวขาถอยหลัง, Glute Bridge, แพลงก์ |
| เสาร์ | Long Run / Walk | วิ่งหรือเดินระยะยาว |
| อาทิตย์ | วันพัก | ยืดเหยียด เดินเบา ๆ |

### Progressive Overload

| สัปดาห์ | วิดพื้น | สควอต | เซต |
|---:|---:|---:|---:|
| 1 | 6 | 10 | 2 |
| 2 | 8 | 12 | 2 |
| 3 | 8–10 | 15 | 2 |
| 4 *(deload)* | 8 | 12 | 2 |
| 5 | 8–10 | 15 | 3 |
| 6 | 10–12 | 15 | 3 |
| 7 | 12 | 18 | 3 |
| 8 *(deload)* | 10 | 15 | 2 |
| 9 | 12 | 20 | 3 |
| 10 | 12–15 | 20 | 3 |
| 11 | 15 | 20–25 | 3 |
| 12 | 15–20 | 25 | 3 |

ท่าอื่นไล่ระดับตามสัปดาห์เช่นกัน เช่น Glute Bridge 12→15 ครั้ง, ก้าวขาถอยหลัง 6→10 ครั้ง/ข้าง, แพลงก์ 15→40 วินาที
สัปดาห์ที่ 4 และ 8 เป็น **Deload** ลดความหนักลงโดยตั้งใจเพื่อให้ร่างกายฟื้นตัว

**ไม่มีการบังคับ** ทำ 100 ครั้งหรือวิ่ง 10 กม. ตั้งแต่เริ่ม — สิ่งเหล่านั้นเป็นเป้าหมายระยะยาวเท่านั้น
ถ้าทำไม่ครบตามเป้า บันทึกจำนวนจริงได้เลย และปรับจำนวนครั้ง/เซตของสัปดาห์นั้นได้ในหน้าโปรแกรม

## เทคโนโลยี

- **Vanilla JavaScript (ES Modules) + Vite** — ไม่มี framework หนัก โหลดเร็ว ดูแลง่าย
- **CSS Custom Properties** สำหรับธีมมืด/สว่าง
- **localStorage** สำหรับเก็บข้อมูลถาวร (ข้อมูลขนาดเล็ก ~90 เซสชันต่อโปรแกรม)
- **SVG ที่เขียนเอง** สำหรับไอคอน ภาพประกอบท่า และกราฟทั้งหมด — ไม่มี chart library และไม่มีไฟล์ภาพภายนอก

Dependency ทั้งหมดของโปรเจกต์: `vite` (dev only) — ไม่มี runtime dependency

## ข้อจำกัดที่ควรทราบ

1. **การแจ้งเตือนทำงานเฉพาะตอนเปิดแอปค้างไว้ในเบราว์เซอร์** — แอปนี้ไม่มี push notification จากเซิร์ฟเวอร์ จึงไม่สามารถเตือนขณะปิดแอปได้ แนะนำให้ตั้งนาฬิกาปลุกในโทรศัพท์ควบคู่ไปด้วย
2. **ไม่มี GPS** — ระยะทางวิ่งต้องกรอกเอง (จากลู่วิ่ง นาฬิกา หรือแอปแผนที่) แอปจะไม่แสดงระยะทางที่ไม่ได้มาจากการกรอกจริง
3. **แคลอรีที่เผาผลาญ** — ไม่แสดง เพราะการประมาณจากน้ำหนักตัวอย่างเดียวคลาดเคลื่อนสูงเกินกว่าจะนำเสนอเป็นตัวเลขจริง
4. **ข้อมูลอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น** — ไม่ซิงก์ข้ามเครื่อง ถ้าล้างข้อมูลเบราว์เซอร์ข้อมูลจะหาย ให้ใช้ส่งออก/นำเข้า JSON เพื่อย้ายหรือสำรอง
5. **หนึ่งวันเก็บได้หนึ่งบันทึก** — ถ้าวันนั้นมีบันทึกการฝึกกล้ามเนื้ออยู่แล้ว จะบันทึกการวิ่งซ้อนในวันเดียวกันไม่ได้ ต้องลบบันทึกเดิมก่อน
6. **ยังไม่ใช่ PWA แบบออฟไลน์เต็มรูปแบบ** — มี manifest ให้ติดตั้งลงหน้าจอได้ แต่ยังไม่มี service worker สำหรับแคชออฟไลน์

## ความปลอดภัย

- วอร์มอัปก่อนฝึกและคูลดาวน์หลังฝึกทุกครั้ง (มีรายการในแอป)
- หยุดทันทีเมื่อเจ็บแปลบ เจ็บข้อ เวียนหัว ใจสั่น หรือแน่นหน้าอก
- ไม่ต้องเพิ่มความหนักถ้าร่างกายยังไม่พร้อม — ฟอร์มที่ถูกต้องสำคัญกว่าจำนวนครั้ง
- หากมีโรคประจำตัวหรือเคยบาดเจ็บ ควรปรึกษาแพทย์ก่อนเริ่มโปรแกรม
